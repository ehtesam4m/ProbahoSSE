# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities using GitHub Security Advisories:

https://github.com/security/advisories

We will review reports privately and respond as quickly as possible.

Please do not open public issues for security-related problems.

## Supported Versions

Only the latest stable version of this project receives security updates.

## Disclosure

Security issues will be disclosed publicly after a fix is released, when appropriate.
