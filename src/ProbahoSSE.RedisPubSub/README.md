# ProbahoSSE.RedisPubSub

Redis Pub/Sub backplane for ProbahoSSE — enables low-latency, fire-and-forget broadcasting across multiple ASP.NET Core server instances. Best suited for scenarios where losing events on reconnect is acceptable.

For full documentation, samples, and source code, visit the GitHub repository:
