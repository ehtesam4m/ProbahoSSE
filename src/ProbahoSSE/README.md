# ProbahoSSE

Multi-instance Server-Sent Events for ASP.NET Core with a pluggable backplane. Built on .NET 10 using the native `TypedResults.ServerSentEvents` API with support for Redis backplanes, connection grouping, keep-alive, and Last-Event-ID replay.

For full documentation, samples, and source code, visit the GitHub repository:

https://github.com/ehtesam4m/ProbahoSSE
