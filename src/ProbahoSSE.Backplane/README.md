# ProbahoSSE.Backplane

Shared backplane infrastructure for ProbahoSSE — provides AOT-compatible SSE event serialization used by all backplane implementations (Redis Pub/Sub, Redis Streams, and custom backplanes).

You do not need to install this package directly. It is pulled in automatically as a transitive dependency of `ProbahoSSE.RedisPubSub` or `ProbahoSSE.RedisStream`.

For full documentation and source code, visit the GitHub repository:

https://github.com/ehtesam4m/ProbahoSSE
